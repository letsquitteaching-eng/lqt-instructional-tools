# Deployment

Upload folder `lqt-surface-deep-transfer-mcp` to `letsquitteaching-eng/lqt-instructional-tools`.

Render: service/root directory `lqt-surface-deep-transfer-mcp`; build `pip install -r requirements.txt`; start `python server.py`.

URL: https://lqt-surface-deep-transfer-mcp.onrender.com/mcp

Set `OPENAI_DOMAIN_CHALLENGE` to the token copied exactly from OpenAI Platform. Leave Challenge Base URL blank, verify, then rescan.
