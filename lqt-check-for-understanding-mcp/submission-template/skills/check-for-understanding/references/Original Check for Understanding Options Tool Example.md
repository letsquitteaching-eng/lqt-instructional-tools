# Original Check for Understanding Options Tool Example

This reference preserves the structure and behavior of the original tool.

## Example interaction
Starter: Help me generate check for understanding options for my learners.

Inputs in the original example:
- Grade Level: 7th
- Learning Target: I can solve two-step equations.
- Timing: Before Instruction

The original tool generated five options:

1. Baseline Activation
Purpose: Elicit what learners already know about equations and operations.
Example prompt: Ask learners to write an equation they remember solving and explain what they would do first and why.
Teacher moves included mini whiteboards, sampling different strategies, and noticing common starting points.

2. Prediction / Anticipation
Purpose: Make thinking visible by predicting how an equation might work.
Example used 3x + 5 = 17 and asked learners to estimate x without fully solving, then explain how they know.

3. Readiness Check
Purpose: Gauge recall of prerequisite skills such as inverse operations and order of operations.
Example asked which operation should be done first in a two-step equation, followed by partner explanation.

4. Concept Connection
Purpose: Connect two-step equations to previously learned one-step equations.
Example compared 2x + 3 = 9 with x + 3 = 9 and asked how solving them differs.

5. Confidence Line-Up
Purpose in the original: Measure perceived confidence/readiness on a 1–4 scale.
Important update for the rebuilt tool: confidence is learner perception, not direct evidence of learning. If a confidence check is used, pair it with a content response or explanation.

## Original response cycle
- RED / Reteach: When most learners misunderstand, briefly model or explain again.
- YELLOW / Clarify: When evidence is mixed, use a contrastive example or focused clarification.
- GREEN / Extend: When most learners demonstrate understanding, move into application, reasoning, or challenge.

The original example ended with a next-lesson/exit prompt asking learners to create a two-step equation with x = 4 as its solution.

## Preserve
- Grade level, Learning Target, and Before/During/After timing.
- 3–5 targeted options.
- Purpose, concrete prompt, and teacher moves.
- A clear response cycle so evidence changes what the teacher does next.
- A brief exit or next-lesson suggestion.
