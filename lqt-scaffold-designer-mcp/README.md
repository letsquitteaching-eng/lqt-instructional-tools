# LQT Scaffold Designer MCP

Two read-only tools: `get_scaffold_framework` and `suggest_scaffold_adjustment`. Preserves the original seven-category structure, including distinct prompts and cues, >=3 examples per section, and evidence-led fading.

Render: root directory `lqt-scaffold-designer-mcp`, build `pip install -r requirements.txt`, start `python server.py`, environment `OPENAI_DOMAIN_CHALLENGE` = exact token copied from OpenAI Platform.
