# Deployment and review

1. Extract the ZIP. Upload the **folder** `lqt-hexagonal-task-mcp`, not this ZIP itself, to your GitHub repository root.
2. Create Render Python web service with `lqt-hexagonal-task-mcp` root, build `pip install -r requirements.txt`, start `python server.py`.
3. Upload separate OpenAI ZIP with the Let's Quit Teaching business identity.
4. On the plugin MCPs tab, connect server `https://lqt-hexagonal-task-mcp.onrender.com/mcp` and confirm both tools.
5. Set Render environment `OPENAI_DOMAIN_CHALLENGE` to the copied verification token, deploy, verify domain (blank Challenge Base URL), rescan to zero findings.
6. Test in browser-based ChatGPT custom MCP connection, including educator-typed Kindergarten, high-school and adult grade responses.
7. Send demonstration video URL for insertion in plugin manifest; upload final review ZIP as a new version and submit.
