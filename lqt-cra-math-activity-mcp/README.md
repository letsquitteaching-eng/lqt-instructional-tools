# LQT CRA Math Activity Generator MCP

Two read-only tools support evidence-responsive Concrete–Representational–Abstract mathematics design.

Render Root Directory: `lqt-cra-math-activity-mcp`. Build: `pip install -r requirements.txt`. Start: `python server.py`.
MCP: `https://lqt-cra-math-activity-mcp.onrender.com/mcp`.

For OpenAI domain verification, add the Render environment variable `OPENAI_DOMAIN_CHALLENGE` with the exact OpenAI-provided token, save/deploy, then verify at `/.well-known/openai-apps-challenge`.
