# LQT Differentiation by Design MCP

Read-only FastMCP tools: `get_differentiation_framework`, `review_differentiation_plan`.

Original framework: shared Learning Target, 2–3 evidence-based pathways, flexible grouping, scaffolds, formative checks, no fixed ability labels. Grade is free text.

Build: `pip install -r requirements.txt`
Start: `python server.py`
Endpoint: `https://lqt-differentiation-by-design-mcp.onrender.com/mcp` (if Render service name is available).

Environment: `OPENAI_DOMAIN_CHALLENGE` = exact token displayed by OpenAI. Challenge base URL blank.
