# LQT Progressive Success Criteria MCP

Preserves the original 2-row × 4-column progression, authored I CAN stems and observable evidence. Accepts all free-text grade levels; returns framework and checks, not externally certified scoring.

Render: Root Directory `lqt-progressive-criteria-mcp`; Build `pip install -r requirements.txt`; Start `python server.py`. URL: `https://lqt-progressive-criteria-mcp.onrender.com/mcp`.

For OpenAI hostname verification set `OPENAI_DOMAIN_CHALLENGE` in Render Environment to the exact issued token, deploy and verify.

Intake is sequential: typed grade → learning target → learner task (upload OR description). Do not generate without task evidence.
