# LQT Write into Learning MCP

Two read-only tools preserve the three-option writing-to-learn workflow and original strategy reference taxonomy.

Render Root Directory: `lqt-write-into-learning-mcp`. Build: `pip install -r requirements.txt`. Start: `python server.py`. Endpoint: `https://lqt-write-into-learning-mcp.onrender.com/mcp`.

Domain verification: add Render environment variable `OPENAI_DOMAIN_CHALLENGE` with token copied from OpenAI Platform and redeploy. OpenAI Challenge Base URL should remain blank.
