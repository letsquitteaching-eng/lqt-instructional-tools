# LQT Quality Rubric Designer MCP

Two read-only tools: `get_quality_rubric_framework` and `review_quality_rubric`. The original rubric skill remains in the companion OpenAI package.

Render: Root Directory `lqt-quality-rubric-mcp`, build `pip install -r requirements.txt`, start `python server.py`. MCP URL: `https://lqt-quality-rubric-mcp.onrender.com/mcp`.

Set `OPENAI_DOMAIN_CHALLENGE` to the exact OpenAI domain verification token in Render Environment, save and deploy. Leave Challenge Base URL blank.
