# LQT Station Rotations hosted MCP

Upload this entire folder to the root of letsquitteaching-eng/lqt-instructional-tools. Render service/root directory: `lqt-station-rotations-mcp`. Build `pip install -r requirements.txt`; start `python server.py`. Endpoint `https://lqt-station-rotations-mcp.onrender.com/mcp`. For domain verification, set `OPENAI_DOMAIN_CHALLENGE` from Platform exact token and redeploy. Grade levels remain unrestricted typed inputs.
